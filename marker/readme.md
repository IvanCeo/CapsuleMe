# 🧥 Fashion Metadata Generator

Этот проект использует **BLIP-2** и **GigaChat** для автоматического создания детальных JSON-метаданных по изображениям одежды.  
Модель генерирует текстовое описание изображения и преобразует его в структурированные данные: категория, стиль, цвет, сезон, материал и описание.

---

## ⚙️ Настройка

1. Создайте файл `.env` в корне проекта и добавьте ключ авторизации GigaChat:
```bash
AUTH_KEY=ваш_ключ_авторизации
```

2. Добавьте изображения, которые хотите обработать, в папку:
```bash
pics/
```

## 🚀 Использование

1. Откройте ноутбук `marker.ipynb`

2. Вызовите функцию в конце ноутбука:
```python
fashion_metadata_pipeline("имя_файла.jpg")
```

3. В консоли появится результат в виде **JSON** с характеристиками одежды:
```yaml
📋 Product Information:
  gender: female
  category: jacket
  style: casual
  color: beige
  season: autumn
  material: cotton
  description: A light beige cotton jacket suitable for everyday wear.
```

## 📁 Структура проекта

```bash
project/
```
